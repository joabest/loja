# SHOPFULL

E-commerce **100% fictício** para demonstração visual e funcional.

## Recursos
- Interface responsiva para desktop e mobile.
- Página de produto inspirada no material visual fornecido pelo proprietário do repositório.
- Produtos e imagens vetoriais fictícios.
- Conta demonstrativa já logada.
- Busca local.
- Variações de produto.
- Carrinho persistido no localStorage.
- Cálculo de frete demonstrativo.
- Checkout fictício com Pix/cartão/boleto sem integração real.
- Avaliações fictícias e formulário de avaliação salvo no localStorage.
- Nenhum pagamento, pedido ou dado da interface representa transação real.

## Deploy

Projeto estático: basta publicar a raiz do repositório em Vercel, Netlify, GitHub Pages ou qualquer servidor HTTP.

Não há dependências nem etapa de build.
